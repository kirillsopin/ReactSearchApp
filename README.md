# React Search App

Навчальний React-застосунок для пошуку користувачів за ім'ям.

## Як запустити у VS Code

1. Розпакуйте ZIP-архів.
2. Відкрийте папку `ReactSearchApp` у Visual Studio Code.
3. Відкрийте термінал: **Terminal → New Terminal**.
4. Виконайте команди:

```bash
npm install
npm run dev
```

5. Відкрийте адресу, яку покаже Vite (зазвичай http://localhost:5173).

## Що реалізовано

- `SearchApp` — головний компонент пошуку.
- `useRef` — зберігає посилання на поле пошуку та дозволяє встановити на нього фокус.
- `useMemo` — кешує відфільтрований список користувачів.
- `useCallback` — кешує функцію фільтрації.
- `useUsers` — власний хук, який завантажує тестовий список користувачів із затримкою.
- Під час завантаження відображається індикатор.
- Пошук працює за ім'ям без урахування великих і малих літер.
- Якщо збігів немає, показується відповідне повідомлення.

Дані користувачів зберігаються у масиві в `src/useUsers.js`. Затримка імітує мережевий запит.
